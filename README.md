# Mario-Bros
Super Mario Bros Ultimate v3.2.2 is an action game developed with Python and Pygame that combines classic platforming mechanics with modern features. Players can control their character using AI-assisted hand tracking via keyboard or camera. It features five different worlds, dynamic weather, a Bowser-Bot boss battle, and retro visual effects.
