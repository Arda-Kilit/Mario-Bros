# Mario-Bros
Super Mario Bros Ultimate v3.2.2, Python ve Pygame ile geliştirilen, klasik platform mekaniklerini modern özelliklerle birleştiren bir aksiyon oyunudur. Oyuncular klavye veya kamera üzerinden yapay zeka destekli el takibiyle karakteri yönetebilir. Beş farklı dünya, dinamik hava durumu, Bowser-Bot boss savaşı ve retro görsel efektler barındırır.
